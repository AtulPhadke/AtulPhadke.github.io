CAP-GENIE

Mass General Hospital, Gene and Cell Therapy Institute, 2024–2025

Bioinformatics

Manuscript in review at Nature Communications

An open-source toolkit for sequencing data from AAV capsid selections and screens. It finds every capsid variant in millions of reads, cleans out sequencing errors, and shows which variants grew against the input library.

How it works

  1. Find the variant in every read

    Each read carries a capsid variant between two known flanks. capgenie finds the flanks and pulls out what sits between them. It can also search against a reference, or match known barcodes with a few mismatches.

  2. Clean out the noise

    Reads below a Phred quality threshold are dropped. Then rare reads one mismatch away from a common variant merge into it, which clears out sequencing and PCR errors.

  3. See which capsids grew

    Each variant is counted in every sample and compared with the input library, which shows how much it grew. Results export to Excel, CSV and JSON.

How it’s built

capgenie is a Python package that hands the heavy work to compiled code. Cython parses the FASTQ files, and multithreaded C++ modules with OpenMP do the matching.

The web app is a Flask server hosted on Heroku, and the same package runs from the command line.

Over 2 million reads a second

Each OpenMP thread takes its own share of the reads. Together with the Cython parser, that cut the runtime by 40%.

The C++ extensions also keep memory use low on large datasets.

Two ways to run it

The same analysis runs as a command-line tool or in a web app.

The paper
