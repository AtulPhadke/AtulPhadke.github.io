Scientists ask for a devserver in Slack and get an EC2 instance with shared EFS storage already mounted.

Scroll to follow one request.

  1. Ask in Slack

    A scientist asks for a devserver in a Slack message, and our Slack app replies.

  2. A devserver comes up

    Terraform and Boto3 bring up an EC2 instance. Every devserver mounts the same EFS share, so everyone sees the same files on any box.

  3. See what’s free

    Demand on each instance updates live, so people can plan experiments around what’s available.

    It became the standard way people got compute at Matterworks.ai.

    An internal tool, so there’s no public code.
